# SmartMove

SmartMove je aplikacija za planiranje i organizaciju putovanja koja na jednom mestu objedinjuje pretragu vožnji, objavu slobodnih mesta, komunikaciju između korisnika i pregled profila putnika i vozača.

Osnovna ideja sistema je da korisniku omogući da na jednostavan način pronađe najpraktičniji način prevoza između dve lokacije, uz mogućnost poređenja različitih opcija i međusobne koordinacije unutar same platforme.

## Struktura projekta

- `frontend/` izvorni statički frontend prototip
- `backend/` Node.js + Express + TypeScript backend sa SQLite bazom i Swagger dokumentacijom
